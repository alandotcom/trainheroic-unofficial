Use these guides to keep a copy of your training or bring existing programming into TrainHeroic.
You need an existing TrainHeroic account. Workout creation in coach programs also requires
coach access to the destination program.

| Your goal | Start here |
| --- | --- |
| Download workout history into Excel or Google Sheets | [Export to CSV, JSON, or text](/export) |
| Keep a paper copy or a PDF of sessions | [Print TrainHeroic workouts](/guides/print-workouts) |
| Build workouts from an Excel sheet or CSV | [Import spreadsheet programming](/guides/import-workouts) |
| Ask an AI assistant about training or draft programming | [Connect TrainHeroic to Claude](/connect) |

For scripts and custom applications, start with the [TrainHeroic API documentation](/developers).
The [integrations overview](/integrations) compares the available connections and file workflows.
