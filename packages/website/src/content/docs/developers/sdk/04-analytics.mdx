Analytics helpers are read-only. TrainHeroic happens to use POST for these report queries, but
the calls do not mutate account data.

```ts
import { analyticsMetricCatalog, queryAnalytics } from "@trainheroic-unofficial/js";

const readiness = await queryAnalytics(client, {
  metric: "readiness-team",
  teamId: 42,
  date: "2026-08-10",
});

console.log(readiness);
console.log(analyticsMetricCatalog());
```

## Metrics

| Metric                     | Scope   | Required inputs                       |
| -------------------------- | ------- | ------------------------------------- |
| `readiness-team`           | Team    | `date`                                |
| `compliance-team`          | Team    | `dateStart`, `dateEnd`                |
| `lift-progress-team`       | Team    | `exerciseId`, `dateStart`, `dateEnd`  |
| `readiness-athlete`        | Athlete | `dateStart`, `dateEnd`                |
| `training-summary-athlete` | Athlete | `dateStart`, `dateEnd`                |
| `lift-1rm-history`         | Athlete | `exerciseId`, `dateStart`, `dateEnd`  |
| `working-max-history`      | Athlete | `exerciseId`                          |

`queryAnalytics` throws a readable error that names any required input you left out.

## Team volume

There is no raw team-volume metric. Pass every athlete id to `training-summary-athlete`, or
use `teamVolume()` to group the per-athlete rows into one rollup.
